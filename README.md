# 🐍 SNAKE.IO (컴퓨터실 대회용)

Firebase Realtime Database로 동작하는 멀티플레이 뱀 게임입니다. 서버 프로그램 없이 정적 파일만 올리면 됩니다.

- `index.html`: 게임 (학번, 이름 입력 후 입장)
- `admin.html`: 관리자 페이지 (라운드 시작/종료, 실시간 접속자, 전체 순위, CSV 저장, 초기화)
- `config.js`: **Firebase 설정을 넣는 유일한 파일**
- `database.rules.json`: Firebase 보안 규칙 (콘솔에 붙여넣기)
- `lib/`: Firebase SDK (학교망에서 CDN이 막혀도 동작하도록 포함)

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → **프로젝트 추가**
2. 이름 입력 → Google 애널리틱스는 **사용 안 함** → 프로젝트 만들기

### 2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)** (한국에서 가장 가까움)
3. 보안 규칙: **잠금 모드로 시작** → 사용 설정
4. 상단 **규칙** 탭 → 내용을 모두 지우고 `database.rules.json` 내용을 붙여넣기 → **게시**
5. **데이터** 탭 상단의 주소(`https://...firebasedatabase.app`)를 복사해 둡니다 (= `databaseURL`)

### 3. 웹 앱 등록
1. 왼쪽 위 ⚙️ **프로젝트 설정** → 아래 **내 앱** → **웹(`</>`)** 아이콘
2. 앱 닉네임 입력 (Hosting 체크는 안 해도 됨) → 앱 등록
3. 나오는 `firebaseConfig = { ... }` 값을 복사

### 4. `config.js` 수정
GitHub에서 `config.js` 파일 → ✏️ 편집 → 3번에서 복사한 값으로 바꿔 넣습니다.
- `databaseURL`이 없거나 다르면 2-5에서 복사한 주소를 넣으세요.
- `ADMIN_PASSWORD`도 바꾸세요.

### 5. GitHub Pages로 배포
1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: 이 파일이 있는 브랜치, 폴더 `/ (root)` → Save
3. 1~2분 후 `https://<아이디>.github.io/snakeiogwansan/` 에서 게임, 뒤에 `admin.html`을 붙이면 관리자 페이지

### 6. 대회 전 꼭 확인
- **학교 PC 한 대에서** 게임 주소에 접속해 로그인 화면에 `🟢 서버 연결됨`이 뜨는지 확인 (교육청 필터가 Firebase를 막는지 확인)
- 학생 2~3명으로 먼저 테스트

## 대회 진행 방법
1. 관리자 페이지에서 **라운드 종료(입장 잠금)** 상태로 두고 학생들이 접속해서 대기
2. **라운드 시작** → 학생들 입장, 게임 진행 (죽으면 바로 다시 하기 가능)
3. **라운드 종료** → 게임 중이던 학생들의 현재 점수까지 기록되고 게임 종료
4. 전체 순위 확인, **CSV 저장** (엑셀로 열림)
5. 다음 반/다음 대회 전에 **전체 기록 초기화**

## 게임 규칙
- 마우스 방향으로 이동, **클릭 또는 스페이스바 = 부스트** (점수 15 이상일 때, 점수가 조금씩 줄어듦)
- ←/→ (또는 A/D) 키로도 조종 가능
- 다른 뱀의 몸에 머리가 닿거나 벽에 닿으면 탈락. 탈락한 뱀은 먹이로 변함
- 다른 학생을 내 몸에 부딪히게 하면 **처치** +1
- 순위 기준: **최고 점수** (관리자 페이지에서 처치순 정렬도 가능)
- 게임 중 다른 창/탭으로 3초 이상 나가면 탈락 (숨어서 무적이 되는 것 방지)
- 같은 학번으로 동시에 두 곳에서 접속할 수 없음

## 참고
- 무료(Spark) 요금제: 동시 접속 100명, 월 다운로드 10GB. 30명이 1시간 플레이하면 약 3~5GB 사용
- 보안 규칙은 누구나 쓰기가 가능한 단순한 형태입니다. 관리자 비밀번호도 브라우저 쪽에서만 확인하므로 교내 대회 용도로만 사용하세요.
