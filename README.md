# 🐍 SNAKE.IO (컴퓨터실 대회용)

Firebase Realtime Database + Cloudflare Pages로 동작하는 멀티플레이 뱀 게임입니다.

```
public/                 정적 파일 (게임, 관리자 페이지, Firebase SDK, IBM Plex 글꼴)
public/i18n.js          번역 (한국어 / English / 中文 / Русский)
functions/api/config.js  GET  /api/config  → 환경변수의 Firebase 주소를 브라우저에 전달
functions/api/admin.js   POST /api/admin   → 관리자 비밀번호 확인 + 게임방 생성/라운드 시작·종료/승점 집계
public/board.html       전광판 (프로젝터용, /board?code=1234)
database.rules.json     Firebase 보안 규칙 (콘솔에 붙여넣기)
```

- 관리자 비밀번호와 Firebase 비밀키는 **Cloudflare 비밀(Secret)에만** 저장되고 브라우저로 내려가지 않습니다.
- 라운드 시작/종료, 기록 초기화, 먹이 초기화는 서버(Cloudflare)만 할 수 있습니다. 학생이 개발자 도구로 직접 하려 해도 보안 규칙에 막힙니다.

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가**
2. 이름 입력 → Google 애널리틱스 **사용 안 함** → 프로젝트 만들기

### 2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)**
3. **잠금 모드로 시작** → 사용 설정
4. **규칙** 탭 → 내용을 모두 지우고 `database.rules.json` 내용 붙여넣기 → **게시**
5. **데이터** 탭 위쪽 주소 복사 (예: `https://내프로젝트-default-rtdb.asia-southeast1.firebasedatabase.app`)
   → 이것이 `FIREBASE_DATABASE_URL`

### 3. Firebase 데이터베이스 비밀키 복사
1. ⚙️ **프로젝트 설정 → 서비스 계정** 탭
2. **데이터베이스 비밀번호(Database secrets)** → 비밀번호 **표시** → 복사
   → 이것이 `FIREBASE_DB_SECRET` (절대 공개 금지)

### 4. Cloudflare Pages 배포
1. https://dash.cloudflare.com → **Workers 및 Pages → 만들기 → Pages → Git에 연결**
   (Workers 화면이 먼저 나오면 아래쪽 "Pages로 배포" 링크를 누르세요)
2. 이 저장소(`snakeiogwansan`) 선택
3. 빌드 설정
   - 프로덕션 분기: 이 코드가 있는 브랜치
   - 프레임워크 프리셋: **없음**
   - 빌드 명령: **비워둠**
   - 빌드 출력 디렉터리: **`public`**
4. **환경 변수**를 추가합니다 (배포 전 화면에서 넣거나, 나중에 **설정 → 변수 및 비밀**에서 추가)

   | 이름 | 유형 | 값 |
   |---|---|---|
   | `FIREBASE_DATABASE_URL` | 텍스트 | 2-5에서 복사한 주소 |
   | `FIREBASE_DB_SECRET` | **비밀(암호화)** | 3에서 복사한 비밀키 |
   | `ADMIN_PASSWORD` | **비밀(암호화)** | 관리자 비밀번호 (직접 정하기) |

5. 배포 완료 후 주소:
   - 게임: `https://<프로젝트명>.pages.dev/`
   - 관리자: `https://<프로젝트명>.pages.dev/admin`

> 환경 변수를 배포 **후에** 추가/수정했다면 **배포 → 최신 배포 ⋯ → 배포 다시 시도**를 해야 적용됩니다.

### 5. 대회 전 꼭 확인
- 학교 PC에서 게임 주소 접속 → 로그인 화면에 `🟢 서버 연결됨`이 뜨는지 확인 (`pages.dev`, `firebasedatabase.app`이 학교망에서 열리는지)
- 관리자 페이지에서 로그인 → **라운드 종료/시작** 버튼이 동작하는지 확인 (실패하면 오류 메시지에 원인이 나옵니다)

## 대회 진행 방법 (게임방 + 라운드)
1. 관리자 페이지(`/admin`) → **대회 관리** 탭 → **새 게임 만들기**
   - 게임 이름, 라운드 수, 라운드 시간(분), 순위별 승점(기본 F1: 25·18·15·12·10·8·6·4·2·1), 처치 보너스(기본 0)
   - 만들면 **4자리 입장 코드**가 나옵니다.
2. **📺 전광판 열기** → 프로젝터에 띄우기 (입장 코드, 남은 시간, 실시간 순위, 누적 순위, 최종 시상대)
3. 학생: 게임 주소 접속 → **게임 코드 + 학번 + 이름** → **대회 입장** → 대기실
4. 관리자: **▶ 라운드 1 시작** → 학생 화면에 3·2·1 카운트다운 후 동시에 시작
   - 라운드 중 죽으면 바로 다시 시작 가능, **그 라운드 최고 크기**가 기록됩니다.
   - 늦게 들어온 학생은 진행 중인 라운드에 바로 참가 (지난 라운드는 0점)
5. 시간이 끝나면 **자동 집계** → 라운드 순위대로 승점 지급 → 학생 화면/전광판에 결과 표시
   - ⚠️ 자동 집계는 **관리자 페이지가 그 게임을 연 상태로 켜져 있어야** 진행됩니다.
   - 급하면 **■ 라운드 즉시 종료**로 일찍 끝낼 수 있습니다 (그때까지의 최고 점수로 순위 결정).
6. 다음 라운드는 두 가지 방법으로 시작됩니다.
   - 학생 결과 화면의 **✅ 다음 라운드 준비 완료**를 **접속 중인 학생이 모두** 누르면 자동 시작 (준비 현황은 학생 화면·관리자·전광판에 표시)
   - 또는 관리자가 **▶ 라운드 N 시작**을 누르면 바로 시작 (안 누르는 학생이 있을 때)
   - 마지막 라운드가 끝나면 **최종 순위 + 시상대**
7. **CSV 저장**: 학번, 이름, 라운드별 승점, 총 승점 (엑셀)
- 동점이면 F1처럼 더 높은 라운드 성적이 많은 학생이 앞섭니다.
- 게임방은 코드별로 분리되어 여러 반이 동시에 해도 섞이지 않습니다. 다 쓴 게임은 목록에서 **삭제**하세요.

## 연습 모드
- 로그인 화면의 **연습 모드로 하기** → 코드 없이 자유롭게 플레이 (기존 방식, 연습 최고 기록 TOP 10)
- 관리자 **연습 모드** 탭에서 열기/잠금, 기록 확인/초기화. 대회 중에는 연습 모드를 잠가 두는 것을 권장합니다.

## 언어 / 글꼴 / 기기
- 오른쪽 위 **KO · EN · 中文 · RU** 칩으로 언어 변경 (게임, 관리자 페이지 모두). 선택한 언어는 기기에 기억됩니다.
- 글꼴은 **IBM Plex Sans** (한글은 Plex Sans KR, 중국어는 Plex Sans SC). 저장소에 포함되어 있어 외부 글꼴 사이트가 막혀도 보이고, 화면에 쓰인 글자 묶음만 내려받습니다.
- **태블릿·폰 가능**: 화면을 터치한 방향으로 이동, 왼쪽 아래 **⚡ 버튼**을 누르고 있으면 부스트 (두 손가락 동시 사용). 가로/세로 모두 됩니다.
  - 폰도 다른 앱으로 3초 이상 나가면 탈락합니다 (알림 내리기, 앱 전환 주의).
  - 컴퓨터(마우스)보다 조작이 조금 불리하므로, 대회는 같은 기기끼리 하는 것을 권장합니다.

## 게임 규칙
- 마우스 방향으로 이동, **클릭 또는 스페이스바 = 부스트** (원작처럼 부스트 중엔 점수가 줄고 꼬리로 먹이가 떨어짐. 10점까지 쓰면 13점이 될 때까지 충전 필요)
- ←/→ (또는 A/D) 키로도 조종 가능
- 다른 뱀 몸에 머리가 닿거나 벽에 닿으면 탈락, 탈락한 뱀은 먹이로 변함
- 다른 학생을 내 몸에 부딪히게 하면 **처치** +1
- 게임 중 다른 창/탭으로 3초 이상 나가면 탈락
- 같은 학번으로 동시에 두 곳에서 접속 불가
- 순위 점수 = **한 판에서 가장 컸던 점수** (부스트로 줄어도 기록은 안 깎임, 게임 중 5초마다 자동 저장)

## 참고
- Firebase 무료(Spark) 요금제: 동시 접속 100명, 월 다운로드 10GB (30명 1시간 ≈ 3~5GB)
- 보안 규칙으로 막는 것: 다른 학생 기록 삭제/깎기, 처치·판수 한 번에 여러 개 올리기, 최고 점수 5000 초과, 라운드 잠금/전체 초기화
- 완전히 막지 못하는 것: 게임 구조상 학생 브라우저가 직접 점수를 쓰므로, 개발자 도구를 잘 아는 학생은 자기 점수를 5000 이하로 조작할 수 있습니다. 순위가 비정상적으로 높으면 관리자 페이지에서 확인하세요.
