# 🎮 컴퓨터실 대회용 게임 (뱀 게임 + 오목 리그)

Firebase Realtime Database + Cloudflare Pages로 동작합니다.

| 주소 | 화면 |
|---|---|
| `game.kakainfo.com/` | 관리자 (Google 계정 로그인) |
| `game.kakainfo.com/snake` | 🐍 뱀 게임 (학생) |
| `game.kakainfo.com/omok` | ⚫ 오목 리그 (학생) |
| `game.kakainfo.com/board?code=1234` | 뱀 게임 전광판 (프로젝터) |

```
public/                 정적 파일 (index.html=관리자, snake.html=뱀 게임, omok.html=오목, Firebase SDK, 글꼴)
public/i18n.js          번역 (한국어 / English / 中文 / Русский)
functions/api/config.js  GET  /api/config  → 환경변수의 Firebase 주소를 브라우저에 전달
functions/api/admin.js   POST /api/admin   → 관리자 구글 로그인 확인 + 게임방 생성/라운드 시작·종료/승점 집계 + 오목 리그 관리
functions/api/omok.js    POST /api/omok    → 오목 리그 학생 등록, 수 두기, 기권, 시간초과 처리
server/                 Cloudflare 함수 공용 코드 (Firebase 호출, 구글 토큰 검증, 오목 리그 규칙·대진 생성)
public/board.html       전광판 (프로젝터용, /board?code=1234)
public/omok.html        오목 리그 학생 화면 (/omok)
public/_redirects       예전 관리자 주소 /admin → /
public/admin.js         관리자 틀 (구글 로그인, 왼쪽 게임 메뉴, 주소 이동, 공용 도우미)
public/snake-admin.js   관리자 — 뱀 게임 화면     public/omok-admin.js  관리자 — 오목 화면
database.rules.json     Firebase 보안 규칙 (콘솔에 붙여넣기)
```

- 관리자는 **Google 계정**으로 로그인하고, 서버가 구글 토큰을 검증한 뒤 `ADMIN_EMAILS`에 있는 이메일만 허용합니다.
- Firebase 비밀키는 **Cloudflare 비밀(Secret)에만** 저장되고 브라우저로 내려가지 않습니다.
- 라운드 시작/종료, 기록 초기화, 먹이 초기화는 서버(Cloudflare)만 할 수 있습니다. 학생이 개발자 도구로 직접 하려 해도 보안 규칙에 막힙니다.

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가**
2. 이름 입력 → Google 애널리틱스 **사용 안 함** → 프로젝트 만들기

### 2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)**
3. **잠금 모드로 시작** → 사용 설정
4. **규칙** 탭 → 내용을 모두 지우고 `database.rules.json` 내용 붙여넣기 → **게시**
5. **데이터** 탭 위쪽 주소 복사 (예: `https://내프로젝트-default-rtdb.asia-southeast1.firebasedatabase.app`)
   → 이것이 `FIREBASE_DATABASE_URL`

### 3. Firebase 데이터베이스 비밀키 복사
1. ⚙️ **프로젝트 설정 → 서비스 계정** 탭
2. **데이터베이스 비밀번호(Database secrets)** → 비밀번호 **표시** → 복사
   → 이것이 `FIREBASE_DB_SECRET` (절대 공개 금지)

### 4. 관리자 Google 로그인 켜기 (Firebase Authentication)
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법** 탭 → **Google** → **사용 설정** → 지원 이메일 선택 → 저장
2. **Authentication → 설정 → 승인된 도메인** → **도메인 추가**: `game.kakainfo.com` (그리고 `<프로젝트명>.pages.dev`)
3. ⚙️ **프로젝트 설정 → 일반** 탭
   - **프로젝트 ID** → 이것이 `FIREBASE_PROJECT_ID`
   - **웹 API 키** → 이것이 `FIREBASE_API_KEY` (공개돼도 되는 값)
   - 웹 API 키가 안 보이면 같은 화면 아래 **내 앱 → 웹 앱(</>) 추가** 후 나오는 `apiKey` 값

### 5. Cloudflare Pages 배포
1. https://dash.cloudflare.com → **Workers 및 Pages → 만들기 → Pages → Git에 연결**
   (Workers 화면이 먼저 나오면 아래쪽 "Pages로 배포" 링크를 누르세요)
2. 이 저장소(`snakeiogwansan`) 선택
3. 빌드 설정
   - 프로덕션 분기: 이 코드가 있는 브랜치
   - 프레임워크 프리셋: **없음**
   - 빌드 명령: **비워둠**
   - 빌드 출력 디렉터리: **`public`**
4. **환경 변수**를 추가합니다 (배포 전 화면에서 넣거나, 나중에 **설정 → 변수 및 비밀**에서 추가)

   | 이름 | 유형 | 값 |
   |---|---|---|
   | `FIREBASE_DATABASE_URL` | 텍스트 | 2-5에서 복사한 주소 |
   | `FIREBASE_DB_SECRET` | **비밀(암호화)** | 3에서 복사한 비밀키 |
   | `FIREBASE_PROJECT_ID` | 텍스트 | 4-3의 프로젝트 ID |
   | `FIREBASE_API_KEY` | 텍스트 | 4-3의 웹 API 키 |
   | `ADMIN_EMAILS` | 텍스트 | 관리자 구글 이메일, 쉼표로 구분 (예: `me@gmail.com, t2@school.kr`). `@school.kr`처럼 쓰면 그 도메인 전체 허용 |

   (예전에 쓰던 `ADMIN_PASSWORD`는 더 이상 쓰지 않으니 지워도 됩니다.)

5. 배포 완료 후 `https://<프로젝트명>.pages.dev/`(관리자), `/snake`, `/omok`이 열리는지 확인

### 6. game.kakainfo.com 연결
1. Cloudflare Pages 프로젝트 → **사용자 지정 도메인 → 사용자 지정 도메인 설정** → `game.kakainfo.com` 입력 → 계속
2. `kakainfo.com`의 DNS가 Cloudflare에 있으면 자동으로 연결됩니다.
   다른 곳(가비아, 후이즈 등)에서 DNS를 관리하면, 거기서 **CNAME** 레코드를 추가하세요:
   이름 `game` → 값 `<프로젝트명>.pages.dev`
3. 상태가 **활성**이 되면 (보통 몇 분, 길면 하루) `https://game.kakainfo.com` 접속
4. Firebase **승인된 도메인**에 `game.kakainfo.com`이 들어 있는지 다시 확인 (없으면 구글 로그인 창에서 오류)

> 환경 변수를 배포 **후에** 추가/수정했다면 **배포 → 최신 배포 ⋯ → 배포 다시 시도**를 해야 적용됩니다.

### 7. 대회 전 꼭 확인
- 학교 PC에서 `/snake`, `/omok` 접속 → 로그인 화면에 `🟢 서버 연결됨`이 뜨는지 확인 (`pages.dev`, `firebasedatabase.app`이 학교망에서 열리는지)
- 관리자 페이지(`/`)에서 구글 로그인 → **라운드 종료/시작** 버튼이 동작하는지 확인 (실패하면 오류 메시지에 원인이 나옵니다)

## 대회 진행 방법 (게임방 + 라운드)
1. 관리자 페이지(`/`) → **대회 관리** 탭 → **새 게임 만들기**
   - 게임 이름, 라운드 수, 라운드 시간(분), 순위별 승점(기본 F1: 25·18·15·12·10·8·6·4·2·1), 처치 보너스(기본 0)
   - 만들면 **4자리 입장 코드**가 나옵니다.
2. **📺 전광판 열기** → 프로젝터에 띄우기 (입장 코드, 남은 시간, 실시간 순위, 누적 순위, 최종 시상대)
3. 학생: `/snake` 접속 → **게임 코드 + 학번 + 이름** → **대회 입장** → 대기실
4. 관리자: **▶ 라운드 1 시작** → 학생 화면에 3·2·1 카운트다운 후 동시에 시작
   - 라운드 중 죽으면 바로 다시 시작 가능, **그 라운드 최고 크기**가 기록됩니다.
   - 늦게 들어온 학생은 진행 중인 라운드에 바로 참가 (지난 라운드는 0점)
5. 시간이 끝나면 **자동 집계** → 라운드 순위대로 승점 지급 → 학생 화면/전광판에 결과 표시
   - ⚠️ 자동 집계는 **관리자 페이지가 그 게임을 연 상태로 켜져 있어야** 진행됩니다.
   - 급하면 **■ 라운드 즉시 종료**로 일찍 끝낼 수 있습니다 (그때까지의 최고 점수로 순위 결정).
6. **▶ 라운드 2 시작** … 반복 → 마지막 라운드가 끝나면 **최종 순위 + 시상대**
7. **CSV 저장**: 학번, 이름, 라운드별 승점, 총 승점 (엑셀)
- 동점이면 F1처럼 더 높은 라운드 성적이 많은 학생이 앞섭니다.
- 게임방은 코드별로 분리되어 여러 반이 동시에 해도 섞이지 않습니다. 다 쓴 게임은 목록에서 **삭제**하세요.

## 오목 리그 (모두가 서로 한 번씩 두는 리그전)
1. 관리자 페이지 → **⚫ 오목 리그** 탭 → **새 오목 리그 만들기**
   - 리그 이름, 한 수 제한 시간(초, 기본 30), 승점(기본 승 3 · 무 1 · 패 0)
   - 만들면 **4자리 입장 코드**와 학생 주소(`/omok?code=1234`)가 나옵니다.
2. 학생: `/omok` 접속 → **게임 코드 + 학번 + 이름** → **등록 / 입장** → 대기 화면
   - 잘못 등록한 학생은 등록 기간에 **빼기**로 지울 수 있습니다.
3. 관리자: **등록 마감 · 대진 만들기** → 무작위 리그 대진 생성
   - **10명 → 9라운드** (짝수 n명 → n−1 라운드), **홀수 n명 → n라운드** (라운드마다 1명씩 쉼, 모두 한 번씩만 쉼)
   - 모든 학생이 서로 **정확히 한 번씩** 만나고, **흑/백 횟수는 고르게** (최대 1번 차이) 나뉩니다.
   - 첫 라운드 전이면 **🔀 대진 다시 섞기**, **등록 다시 받기** 가능
4. **▶ 라운드 k 시작** → 학생 화면에 3·2·1 후 각자 자기 대국판이 열림 (흑부터)
   - 5개 이상 이으면 승리 (6목도 승리, 금수 없음), 한 수 제한 시간을 넘기면 패배, **기권** 버튼 있음
   - 컴퓨터는 클릭, 태블릿·폰은 **같은 자리를 두 번 탭**하면 돌이 놓입니다 (잘못 누름 방지)
   - 관리자 화면에 라운드별 대국 상태(수, 결과)와 실시간 순위, **보기**로 대국판 확인
   - **관전 모드**: 자기 대국이 끝났거나 쉬는 차례인 학생은 오른쪽 **👀 라운드 관전** 목록에서 같은 라운드의 다른 대국을 실시간으로 볼 수 있습니다 (보기만 가능). 자기 대국이 진행 중일 때는 관전할 수 없고, 다음 라운드가 시작되면 자동으로 자기 대국판으로 돌아갑니다.
5. **■ 라운드 k 종료** → 아직 안 끝난 대국은 **무승부** (차례인 학생의 시간이 이미 지났으면 그 학생 시간패)
6. 마지막 라운드가 끝나면 **최종 순위** (학생 화면에 최종 등수·승점 표시) → **CSV 저장** (순위, 승·무·패, 승점, 라운드별 상대/결과)
- 순위: **승점 → 승자승(동점자끼리 얻은 승점) → 다승**
- 결과를 바꿔야 하면 대국 표의 **판정…**에서 흑 승/백 승/무승부를 직접 정할 수 있습니다 (지난 라운드도 가능, 순위 즉시 반영).
- 학생은 등록한 기기에서만 둘 수 있습니다 (다른 학생 대신 두기 방지). 새로고침해도 자동으로 다시 들어갑니다.
  컴퓨터를 바꿔야 하면 관리자 **등록한 학생** 표에서 **로그인 초기화** → 새 기기에서 같은 학번으로 입장하면 이어서 둡니다.
- 수 두기·승패 판정은 모두 서버(Cloudflare)가 하므로 개발자 도구로 대국 결과를 조작할 수 없습니다.
- ⚠️ `database.rules.json`이 바뀌었으니 **Firebase 콘솔 규칙 탭에 다시 붙여넣고 게시**하세요 (`omok`, `omokIndex` 추가).

## 관리자 화면 구성
- 왼쪽 **게임 메뉴**(🐍 뱀 게임, ⚫ 오목) → 위쪽에 학생 주소(복사/열기)와 하위 탭(뱀 게임: 대회 · 연습 모드)
- 왼쪽 **목록**(상태 표시: 입장 대기/진행/종료 등) → 오른쪽 **상세**: 진행 단계, **다음 할 일**과 그 단계의 버튼, 순위·대국 표
- 주소에 화면이 기억됩니다 (예: `/#omok/leagues/1234`). 새로고침하거나 그 주소를 북마크해도 같은 화면이 열립니다.

### 새 게임 추가하기 (개발용)
1. `public/새게임.html` (학생 화면, `/새게임` 주소로 열림)
2. `public/index.html`에 `<section class="game" data-game="새게임"><div data-view="목록화면">…</div></section>`
3. `public/새게임-admin.js`에서 `Admin.register({ id, icon, name, path, views, start(ctx), route(view, arg) })`
   (`snake-admin.js`, `omok-admin.js`가 예시) → `index.html` 아래쪽 `<script>`에 추가
4. 서버 작업이 필요하면 `server/새게임.js`에 관리자 작업을 만들고 `functions/api/admin.js`의 `ACTIONS`에 합치기
5. HTML에서 불러오는 js/css 주소 끝의 `?v=…` 값을 새 값으로 바꾸기 (브라우저에 남은 예전 파일과 섞이지 않게)
6. 문구는 `admin-i18n.js` 같은 파일에 `I18N.extend({ ko: {...}, en: {...}, zh: {...}, ru: {...} })`

## 연습 모드
- 로그인 화면의 **연습 모드로 하기** → 코드 없이 자유롭게 플레이 (기존 방식, 연습 최고 기록 TOP 10)
- 관리자 **연습 모드** 탭에서 열기/잠금, 기록 확인/초기화. 대회 중에는 연습 모드를 잠가 두는 것을 권장합니다.

## 언어 / 글꼴 / 기기
- 오른쪽 위 **KO · EN · 中文 · RU** 칩으로 언어 변경 (게임, 관리자 페이지 모두). 선택한 언어는 기기에 기억됩니다.
- 글꼴은 **IBM Plex Sans** (한글은 Plex Sans KR, 중국어는 Plex Sans SC). 저장소에 포함되어 있어 외부 글꼴 사이트가 막혀도 보이고, 화면에 쓰인 글자 묶음만 내려받습니다.
- **태블릿·폰 가능**: 화면을 터치한 방향으로 이동, 왼쪽 아래 **⚡ 버튼**을 누르고 있으면 부스트 (두 손가락 동시 사용). 가로/세로 모두 됩니다.
  - 폰도 다른 앱으로 3초 이상 나가면 탈락합니다 (알림 내리기, 앱 전환 주의).
  - 컴퓨터(마우스)보다 조작이 조금 불리하므로, 대회는 같은 기기끼리 하는 것을 권장합니다.

## 게임 규칙
- 마우스 방향으로 이동, **클릭 또는 스페이스바 = 부스트** (원작처럼 부스트 중엔 점수가 줄고 꼬리로 먹이가 떨어짐. 10점까지 쓰면 13점이 될 때까지 충전 필요)
- ←/→ (또는 A/D) 키로도 조종 가능
- 다른 뱀 몸에 머리가 닿거나 벽에 닿으면 탈락, 탈락한 뱀은 먹이로 변함
- 다른 학생을 내 몸에 부딪히게 하면 **처치** +1
- 게임 중 다른 창/탭으로 3초 이상 나가면 탈락
- 같은 학번으로 동시에 두 곳에서 접속 불가
- 순위 점수 = **한 판에서 가장 컸던 점수** (부스트로 줄어도 기록은 안 깎임, 게임 중 5초마다 자동 저장)
