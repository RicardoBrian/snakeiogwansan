## 3. 선정 결과 발표 (축제 당일 아침)
1. `/admin` 로그인 → 표에서 학생별 신청 종목 체크박스 = **선정** (체크하는 순간 저장, 아직 학생에겐 안 보임)
   - "선정자만", "같은 부 중복만" 필터와 종목별 신청/선정 인원 확인 가능. 같은 부 두 종목을 모두 선정하면 ⚠ 표시
2. **[결과 공개하기]** → 체크 안 된 학생은 "미선정"으로 처리되고, 학생들이 [📜 선정 결과 확인]에서 조회 가능
3. 학생은 **신청할 때 쓴 이름 + 학번**을 입력해야 결과가 나옵니다 (띄어쓰기·대소문자는 무시)
   - 공개 전: "아직 발표 전" / 이름·학번 불일치: "장부에서 찾을 수 없다" / 선정: 시간·컴퓨터실 안내 / 미선정: 위로 대사
4. 공개 후에도 체크를 바꾸면 바로 반영됩니다. **[공개 중지]**로 다시 숨길 수 있습니다.
5. 공개 뒤에 들어온 늦은 신청자는 결과 문서가 없어 "찾을 수 없다"가 뜹니다 → 공개 중지 후 다시 공개하면 생성됩니다.

보안: 결과 문서 ID는 `SHA-256(학번+이름)`이고 내용에는 이름·학번이 없습니다. 목록 조회가 막혀 있어서
다른 학생의 이름과 학번을 모두 알아야만 그 학생의 결과를 볼 수 있습니다. 신청서 자체는 여전히 관리자만 읽을 수 있습니다.

## 동작 메모
- **중복 방지**: 문서 ID가 학번이라 두 번째 저장은 "수정"이 되고 규칙이 막습니다. 잘못 신청한 학생은 콘솔에서 문서를 지운 뒤 다시 신청.
- **학번 형식**: `public/app.js`의 `STUDENT_ID_RE`와 `firestore.rules`의 `'^[0-9]{5}$'`를 함께 수정.
- **종목 이름**: `public/shared.js`의 `game`과 `firestore.rules`의 목록(두 군데)을 함께 수정. 화면 이름은 `i18n.js`.
- **접근성**: 대사는 말풍선 탭/엔터/스페이스로 넘김(타자 중 탭하면 문장 즉시 완성). 기기 "동작 줄이기"가 켜져 있으면 타자 효과와
  바위 연출 없이 바로 진행. 화면 낭독기에는 대사 전체가 한 번에 읽힘.
- 오범석 박사 그림은 `app.js`의 SVG로 직접 그린 캐릭터입니다.
